# s-matrix

Библиотека `s21_matrix.h` на C для работы с матрицами.

## Функции
Создание/удаление, сравнение, сложение/вычитание, умножение на число и на матрицу, транспонирование, матрица алгебраических дополнений, определитель, обратная матрица.

## Сборка
```bash
cd src
make            # собрать библиотеку
make test       # unit-тесты
make gcov_report
```

Полное задание — в [README_RUS.md](README_RUS.md).
